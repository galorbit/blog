# 超聚变CX5200 V5手动设置风扇转速

> 手动设置风扇服务器断电后会失效，需要再次设置

ssh连接IBMC
`ssh Administrator@192.168.2.100`

登录后使用以下命令:

```text
ipmcset -d fanmode -v 1 0
#设置风扇模式为手动并且不超时
ipmcset -d fanlevel -v 80
设置风扇转速为80%

```
